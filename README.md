# Lingva
**[Lingva](http://185.40.105.117:8080/)** - онлайн-платформа для исполнения и статического анализа кода. Платформа спроектирована с упором на интерактивность (поддержка ввода/вывода в реальном времени) и строгую архитектурную изоляцию.

### Возможности 
* **Интерактивное выполнение**: поддерживается ввод/вывод в реальном времени
* **Статический анализ**: встроенный сервис анализа проверяет синтаксис и стиль кода
* **Поддержка языков**: Python, Go, C, C++

### API
1. ```POST /rest/analyze```: Анализ кода. Взаимодействие происходит по HTTP.
2. ```GET /ws/run```: Исполнение кода. Взаимодействие происходит через web socket. 
Первый запрос -- сетап в формате:
   ```json
      {
        "Setup": {
           "Lang": "example_lang",
           "Code": "source_code"
        }
      }
    ```
   Далее поток ввода в формате:
    ```json
    {
      "Stdin": "example stdin"
    }
    ```
3. ```GET /```: фронтенд приложения.
    

### Архитектура 
Проект разделен на микросервисы, взаимодействующие по протоколу gRPC
1. **API Gateway**: единая точка входа в приложение. Принимает HTTP/WebSocket запросы, выступая в роли оркестратора.
2. **Analyzer**: сервис статического анализа кода
3. **Runner**: сервис выполнения кода

### Структура сервисов
##### API Gateway
```text
internal/
├── app/                  # DI-контейнер и сборка приложения
├── clients/              # Реализация клиентов
├── transport/            # Транспортный слой
│   ├── rest/             # REST обработчики
│   └── websocket/        # WebSocket обработчики
```

##### Runner и Analyzer
```text
internal/
├── app/                  # DI-контейнер и сборка приложения
├── core/                 # Ядро: чистая бизнес-логика
│   ├── domain/           # Доменные модели
│   └── ports/            # Интерфейсы
├── adapters/             # Инфраструктурный слой
│   ├── in_grpc/          # Входящий адаптер: gRPC-сервер
│   └── out_docker/       # Исходящий адаптер: реализация песочницы через Docker SDK
```

### Технологии 
* **Язык программирования**: Go
* **Сетевое взаимодействие**: gRPC, HTTP, WebSocket
* **Архитектурные паттерны**: микросервисы, гексагональная архитектура, DI
* **Инфраструктура**: Docker SDK
* **Логирование**: slog
